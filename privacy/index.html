01What this site is

Coldline is a working software MVP with a browser-local workspace. This notice describes its current data handling and optional connected AI service. An optional Azure runtime implements organization accounts and shared tenant storage; it is separate from the public GitHub Pages demonstration.

02Information entered in the demo

Sample records are included in the website source. New records and edited notes are saved in localStorage. A demo session flag is saved in sessionStorage. Accepted analysis reports and pilot brief drafts are also saved in localStorage. User-uploaded image bytes are not saved with accepted reports. Prepared-example interactions do not send the entered content to an application server. The optional connected-analysis form sends its text and selected images to the service address you specify when you choose Analyze with connected service. That service can send them to its configured AI provider. Its retention and access policies apply.

03Passwords and account information

The visible demo password is a public example. It is checked in the browser and is never stored by the application. Do not enter a password used for another service. The demo email does not create an account. In the configured organization runtime, Microsoft Entra ID handles sign-in and authentication cookies. The API receives the platform identity, checks an approved membership and role, and applies any trial expiry. Coldline does not collect or store your Microsoft password.

04Hosting and external services

The site is hosted by GitHub Pages. Ordinary requests may be logged by the hosting provider under its privacy policy. Photographs and font files are included locally. The public GitHub Pages version adds no analytics, advertising pixels, tracking cookies, or third-party form processor. A configured Azure runtime uses the platform’s authentication cookies and request telemetry; its operator must publish the actual region, retention, and contact details.

05Retention and deletion

Saved draft, record and accepted analysis data remains until you clear browser storage or use Reset demo data. A browser-local session flag normally ends when that tab session closes. Reset affects this brand in the current browser. It does not delete downloaded CSV or brief files.

06Your choices

Use sample content only. You can explore without entering personal information by choosing the one-click demo. You can export records, download a pilot brief and reset saved data. The production operator must complete its privacy notice and data agreement before processing real personal or confidential operational information.

07Free-form requests and organization records

On GitHub Pages, the form prepares a downloadable request; it does not send it. The GitHub link opens a generic public enquiry. Details entered in the form stay in the downloadable draft unless you choose to share them. In an enabled Azure runtime, submitting the form sends the name, email, organization, request type, preferred time, and message to the private enquiry API. Only a configured product-owner account can retrieve enquiries. A salted request-source hash supports rate limiting.

Organization shipment records, source text, connected reports, reviewer actions, and usage measurements are stored in tenant-scoped Azure containers. Uploaded image bytes are sent for analysis and are not saved in the report archive. Audit events record the actor, action, organization, and time. Application request telemetry excludes evidence text and form fields. Retention, account access, backups, and deletion requests require the operating company’s published policy.
