01Current storage

Sample register changes, retained reports and pilot drafts are stored under brand-specific keys in this browser. Demo access uses sessionStorage. They are not shared between operators or backed up by this static website. The separately activated organization runtime stores records on the server and starts with the organization’s own empty register; it does not import public sample data.

02Connected analysis

The connected-analysis action transmits entered text and selected images to the configured service. In the organization runtime, the address is fixed to the same-origin authenticated API. Its server sends an attached shipment PDF to the configured Azure Document Intelligence resource and sends extracted text to the configured AI model. The organization report retains the extracted text and source reference. Review that provider’s account, region, agreement and retention settings before using real organizational data.

03Server-side credentials

Provider keys and Azure authentication tokens belong in the server environment. They are never placed in the website’s public JavaScript. A service token used by the connected form is held for the request and is not saved in report history.

04Temporary server cache

The optional adapter caches a limited number of identical review results in memory for ten minutes. Reports may contain quoted input text. The cache is not a production evidence archive.

05Retention and deletion

Reset demo data clears this brand’s local records, drafts, accepted reports and session in the current browser. It does not remove downloaded files or data already submitted to a separately configured service.

06Organization storage in Azure

The Azure API implements tenant-scoped shipment records and reports, role checks, conditional updates, and durable audit events. The deployment templates configure encrypted Blob Storage, versioning, Key Vault, and request telemetry. Those services require an actual deployment. Regional data residency, retention locking, backup recovery, and access reviews must be verified for that deployment.

07Before a real-data pilot

Define organization access, permitted data categories, retention, deletion, backups and incident responsibilities. Publish the actual operating company and private contact channel before accepting confidential or personal operational data.
